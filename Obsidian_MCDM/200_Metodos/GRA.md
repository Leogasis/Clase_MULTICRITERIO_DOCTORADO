# 🔧 Grey Relational Analysis (GRA)

**[[Mapa del curso (MOC)|<< Volver al Mapa del Curso]]**

## 📝 Descripción General
Método de la teoría de sistemas grises utilizado para evaluar el grado de relación entre secuencias de datos mediante coeficientes de relación gris.

## 📐 Estructura Matemática Básica
Grado de relación gris computado sobre diferencias absolutas de datos normalizados.

## ⚠️ Límites y Consideraciones
- Excelente rendimiento con muestras de datos muy pequeñas o incompletas.
